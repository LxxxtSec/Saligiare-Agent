# Saligiare v0.1.0 本地基线

Saligiare v0.1.0 是一个可运行、可测试、可审计的本地 Agent 基线。它的目标是把安全 Agent 最重要的边界先固定下来，而不是声称已经能够通过所有安全 benchmark。

## 已包含

- `Task`、`Action`、`Observation`、`Result` 等核心协议；
- 有最大步数的不可变运行状态和 Agent Loop；
- 类型化 Tool Registry、EchoTool 和 Policy Guard；
- Policy Decision、Tool Execution 审计日志；
- Fake Sandbox 和 Docker Sandbox；
- 非 root、默认无网络、只读根文件系统、资源限制和 workspace 挂载；
- 严格结构化 JSON 模型响应，只接受合法 `Action` 或明确的 `null` 停止信号；
- Fake Provider，确保所有单元测试不需要网络或 API Key；
- Prompt 版本化和确定性上下文渲染；
- Provider 错误分类和有限重试；
- 从模型响应到策略检查、工具执行和观察结果的端到端测试。

## 当前验证证据

```text
全量单元测试：89 passed, 1 skipped
Docker smoke test：1 passed
Ruff：All checks passed
git diff --check：通过
```

Docker smoke test 必须显式开启，并且只在本地 Docker Desktop daemon 可用时运行：

```bash
SALIGIARE_DOCKER_SMOKE=1 \
SALIGIARE_SANDBOX_IMAGE=saligiare-sandbox:test \
python -m pytest tests/sandbox/test_docker_smoke.py -q
```

## v1 的安全边界

模型只能提出结构化动作，不能直接取得宿主机权限。确定性代码负责：

1. 校验模型 JSON 和 `Action` Schema；
2. 检查任务允许的 capability；
3. 选择已注册工具；
4. 在 Fake 或 Docker Sandbox 中执行命令；
5. 保存工具、策略和运行结果。

## v1 暂不包含

- 真实模型厂商 API 和 API Key 管理；
- TSECBENCH、Cybench、CyberGym 等 benchmark 适配器；
- Linux Kernel、Android 或 WebKit 的专用源码分析器；
- 真实互联网目标扫描、真实 SRC 凭证和未授权测试能力；
- 将模型自然语言结论直接当作漏洞或 benchmark 成功证据。

这些内容属于 v1.1 及后续阶段，必须在现有协议、沙箱和评测器基础上逐步加入。
